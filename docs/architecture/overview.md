# 架构概览

## 页面入口

- `index.html`：页面骨架和挂载节点。
- `css/style.css`：界面样式、主题、地图和房间面板。
- `js/main.js`：当前主进程、规则、联网状态和界面渲染的集中实现。

后续重构目标是把 `js/main.js` 按以下边界拆分：

- `js/core/`：随机数、种子、地图拓扑和纯数据。
- `js/game/`：爬塔状态、战斗、奖励、存档和战绩。
- `js/app/`：应用视图、配置、持久化和事件协调。
- `js/presentation/`：计时表现、提示、地图动画和主题。
- `js/tutorial/`：独立新手引导流程。
- `js/ai/`：可选题目和难度分析逻辑。

## 联机服务

`server.js` 提供静态页面、洛谷题单代理、VJudge 验证接口和 WebSocket 房间管理。

合作模式由服务器维护共享投票和战斗状态；团队竞速由客户端维护独立爬塔状态，服务器只同步成员位置、进度和房间状态。

## 构建与部署

`npm run build` 将入口和静态资源复制到 `dist/`。Netlify 使用 `dist/` 发布静态页面，本地服务器直接读取项目根目录并返回相同入口与资源。
