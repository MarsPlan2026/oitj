# 我做了一个把 OI 刷题变成《杀戮尖塔 2》式冒险的小游戏

**在线体验：**[OI 尖塔 II](https://oitj.onrender.com)  
**GitHub 仓库：**[MarsPlan2026/oitj](https://github.com/MarsPlan2026/oitj)

> **国内访问提示：**游戏目前部署在 Render，国内网络可能无法直接访问，或访问不稳定。如果打不开，可以按照下方的「本地游玩」步骤运行游戏。

## 灵感从哪里来？

后来，《杀戮尖塔 2》传到了机房，给了我一个新点子。《OI 尖塔》最开始其实是个纸质游戏，但玩着玩着，我发现纸质版还是不太方便。

于是我就喊来 **Copilot Agent** 帮忙，把这个点子做成了一个网页小游戏。

平时刷题，做完一道就去找下一道，题目之间好像总少了点目标感。我想试试给每道题一个更明确的身份：它不只是题库里的一道题，也是挡在冒险路上的敌人。做出来，就能继续向塔顶前进；如果卡住了，时间和生命也会慢慢带来压力。

这就是《OI 尖塔 II》的核心想法：**把每一场战斗换成一道题。**一边做题，一边规划路线、选择补给、决定要不要冒险，看看自己能不能一路爬到最后。

## 一局游戏怎么玩？

游戏分为普及、提高、省选三个大难度，每个难度各有 0 到 10 共 11 个进阶。每个进阶都要依次闯过三幕，每一幕是一座 **15 层的塔，塔顶有 Boss**。打败三幕的 Boss，就算完成这个进阶，并解锁同一难度下的下一级。

每座塔的底部都有一位先古遗民，会给你三种随机增益供你选择。选好之后，就可以开始爬塔了。一路上，你会在地图的岔路口选择前进方向。路线不同，接下来遇到的房间和能拿到的资源也不同。

地图里有各种各样的房间：

- **小怪和精英**：需要完成对应难度的题目。精英更危险，但会掉落遗物。
- **休息处**：回复生命，或为接下来的战斗做准备。
- **商店**：用一路攒下的金币购买药水、遗物和其他补给。
- **宝箱**：有机会拿到额外奖励。
- **未知房间**：包含三十多种随机事件，可能遇到交易、选择或奖励，也可能变成战斗、商店或宝箱。
- **Boss**：每座塔顶的最终挑战。获胜后可以从遗物中选择一件，再前往下一幕。

路线没有绝对正确的答案。血量不多时，也许该绕去休息；金币充足时，可以考虑去商店补给；状态不错的话，也可以挑战精英，争取拿到遗物。每次选择都要结合自己的状态来判断。

## 解题就是战斗

进入战斗后，游戏会给出题目难度范围和建议题型。你可以从洛谷题库里随机抽题，也可以使用自己设置的洛谷题单，或者自己找题。

选好题目后开始计时。题目 AC 后，点击按钮结算战斗；绑定 VJudge 后，也可以由系统核验提交记录。战斗没有放弃选项：要么把题做出来，要么在超时扣血中继续坚持，直到生命耗尽。

普及和提高难度下，小怪、精英和 Boss 的宽限时间分别是 20、40 和 60 分钟；省选难度下则分别是 60、90 和 120 分钟。宽限时间内不会因为超时扣血；超过之后，每满 5 分钟扣一次生命。小怪和精英的基础扣血量是 10 点，Boss 是 20 点，实际扣血还会随阶段和难度变化。计时按系统时间计算，刷新页面不会重置。

题目难度也会随着进度变化：普及、提高、省选对应不同的洛谷难度颜色范围；同一个大难度里，进阶越高、阶段越靠后，题目就越接近颜色范围的上限。同一阶段中，Boss 通常比精英难，精英又比普通敌人难。

## 题目来源可以自己安排

随机跳题会根据当前战斗的难度范围，从本地保存的洛谷题库中抽题。你也可以在「题库 / 题单设置」里导入题库、调整筛选条件，或者添加一个或多个洛谷题单。勾选题单后，随机抽题就会优先从选中的题单里抽取。

你可以直接用默认题库挑战，也可以把正在学的专题、训练计划或收藏题单导进来，让爬塔更贴合自己的练习目标。

## 也可以和朋友一起爬

游戏支持多人联机。队伍里的玩家共享地图和种子，也会一起决定下一步走哪条路：每个人都可以给下一个节点投票，票数最多的路线成为全队的选择；如果平票，就随机决定。

进入战斗后，全队共享当前这一组题。任何一个人抽题，其他人也能看到；队伍需要完成的题目数量会根据人数计算，至少一道。有人 AC 某道题后，这道题就算被全队击败；所有题目完成后，大家各自结算奖励。

每个人的生命、金币和遗物仍然是自己的。倒下的玩家会转为观战；如果全队都倒下，这一局就失败了。联机时还可以在地图上画路线规划，队友也能看到你的笔迹。

### 本地游玩（Windows）

1. 从 [GitHub Releases](https://github.com/MarsPlan2026/oitj/releases/tag/v1.1.2) 下载项目。
2. 确认电脑已安装 **Node.js**，并在项目文件夹中打开终端。
3. 运行 `node server.js`，保持终端窗口运行。
4. 在浏览器中打开 `http://localhost:8787`。
